# Digital_Department

Репозиторий содержит набор учебных заданий, выполненных в рамках Цифровой кафедры, посвящённых базовым и продвинутым методам анализа данных и машинного обучения на Python.

Используемые библиотеки: pandas, numpy, scikit-learn, matplotlib, seaborn.

**Задание 1** ( [пингвины](https://github.com/VeronikaSteklo/Digital_Department/blob/main/%D0%9F%D0%B8%D0%BD%D0%B3%D0%B2%D0%B8%D0%BD%D0%BE%D0%B2%D0%B0%D1%8F%D0%A6%D0%B8%D1%84%D1%80%D0%B0.ipynb) ) - Разведочный анализ и подготовка данных

Задача: провести EDA и подготовить данные для дальнейшего машинного обучения.
Данные: сокращённый датасет с характеристиками пингвинов.

Что сделано:
- разведочный анализ данных и визуализация распределений;
-	обработка пропусков;
-	нормализация числовых признаков;
-	кодирование категориальных признаков;
-	снижение размерности с помощью PCA;
-	анализ влияния преобразований на структуру данных.
